## 4. Leakage and protocol checks

- Partitions 1-4 are the only rows any model, scaler, grid choice or threshold saw; the unit
  tests assert that no fold trains on its own validation partition or on partition 5.
- Identical sequences already share a partition (Phase 6); no random split was used.
- The test block can be written once: `--evaluate --test` refuses when the manifest is missing,
  unsound or already has a test block, and `--check` fails unless `touches` is exactly 1.

## 8. Deviations

1. **Rule row uses tuned thresholds**, not the engine's own tau. That tau comes from a fit on the
   synthetic reference set (`inference/service.py`); using it would score the rules against
   synthetic data.
2. **Three tasks**, not localization only (your choice at gate B).
3. **Extra modules**: `protloc/training/baseline_models.py` (numerics, lazily imported),
   `backend/rules/baseline_class_map.yaml` (class tables as data), `--smoke` and `--test` modes.
4. **Stages ran on two machines**: features on Linux, training on Windows. The manifest records the
   hardware of each stage. Training seconds cover only the last `--train` invocation.
5. **`--smoke` runs** (every 25th row) were used to test the code; no number from them appears here.
6. **`configs/evaluation/default.yaml` is unedited** (Phase 9 owns it); ADR-0010 records the +1 mapping.

## 9. UNVERIFIED

- That the baselines reproduce bit for bit on another machine; stages ran on two platforms and no
  rerun was compared.
- The DeepLoc targets themselves, and any claim of parity with DeepLoc.
- That the nested-threshold scheme is leak-free: thresholds for fold *k* come from scores of
  models that had fold *k* in training (ADR-0010 §4).
- The effect of applying thresholds tuned on three-partition models to a four-partition model.
- Why validation and test differ for some classes (for example transmembrane MCC for LogReg,
  0.712 validation vs 0.874 test); only the numbers were measured, not a cause.
- Docker, GitHub Actions and the frontend gate: nothing there changed and none was run.
