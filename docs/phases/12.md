## 4. Leakage and protocol checks

- Counts and vocabulary use the subset mask only (`counts_scope: "subset_mask"`); a unit test fails if the whole-corpus label table is read.
- `--evaluate` recomputes every fold's scores from the saved fold weights: max absolute difference 0.00e+00 (tolerance 1e-9), decisions identical.
- The nested threshold for fold k is tuned on the other partitions; the frozen one on all four. Partition 5 was not read before `--freeze` (`touches: 1` is recorded by the one test run).
- `--check` (no data bytes): torch 2.14.1; 8 grid points; floor 20; policy [experimental, curated]; earlier touches {localization: 1, crf: 1}.

## 8. Deviations

1. **Gamma is an axis with one value** ([0.0]), so the grid is 8 points, not 16.
2. **Only 12 terms are trainable** at a floor of 20 on the 500-sequence subset (gate B2); 705 terms are recorded as under the floor.
3. **"Fmax" is F at a nested global threshold**, not an oracle maximum; precision is averaged over rows with a prediction, recall over evaluable rows.
4. **The calibration cross-fit is written in `go.py`**, not `cal.crossfit`, because the threshold is one global Fmax threshold rather than a per-label MCC threshold; the Phase 10 per-term machinery (`fit_label`, `LabelCalibrator`, `calibration_report`) is reused and the Platt fallback is off.
5. **The selection among grid points is within noise**: the top four selectors are 0.5929 / 0.5923 / 0.5892 / 0.5890.
6. **A unit test used the wrong batch size** (8 against the plan's 4), so reproduced scores differed by 6e-8 on your machine; the test was fixed. The script itself reproduces to 0.0.
7. **A stale 0-byte `.git/index.lock`** was deleted after your approval (gate E).
8. **`data/go/_stage.tgz`** is a staging archive I made to check the code in a cloud copy; it is in gitignored `data/go/` and I could not delete it. Delete it when convenient.
9. **`--smoke` runs** tested the code on real data; no number from them appears here.
10. **The refuse-to-start check and `MAX_BATCH_SEQUENCES` are deferred to Phase 14** (gate F), as for the earlier heads.
