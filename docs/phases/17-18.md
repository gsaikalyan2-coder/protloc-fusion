# Phase 17-18: Limits, errors, degraded states, and the sequence viewer

Branch `phase/17-18-limits-viewer`, from `main` (Phase 16, v0.16.0). Spec: `PROJECT_PLAN.md` §4 rows 17 and 18. Decision: `docs/adr/ADR-0018-nightingale-deferred.md`.
No metric or timing was measured in this phase.

**Scope: "subset (500), not comparable to DeepLoc or to the Phase 8 full-corpus numbers". 500 cached sequences, two served groups (`eukaryote`, `plant`), gallery sequences in-sample, attribution is faithfulness to the head and not biology. Result URLs are not access-controlled.**

## 3. Facts measured

None. Limits are constants: 5,000 residues (`MAX_SEQUENCE_LENGTH`, equal to the scanner's cap), 2,000,000 characters per request field, `MAX_BATCH_SEQUENCES` (20 at Phase 14) per batch.

## 4. Parity, refusal and independence checks

Catalog tests: unique codes, valid statuses, every refusal mapping targets a real code, retryable only for `structure_refused`, `demo_disabled`, `job_failed`. FASTA tests: each fault with its line. API tests (stub engine): each refusal path returns its code before queueing. Serving remains numpy; no `training/` import; evidence never feeds a score.
