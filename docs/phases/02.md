## Decided

- **Acceptance host: Render free tier** (operator declined `gcloud`). Cloud Run was the
  first recommendation and was not deployed. **The host for the real serving image is
  undecided**: HF Docker needs PRO ($9/month); Render free has 512 MB, too small for
  ESM-2 650M; Cloud Run fits on paper and is unverified. See ADR-0007 §3.3.
- Frontend stays an HF Static Space; artifacts stay on the HF Hub.

## Findings that differ from the brief

- Cloud Run's quotas page says *"There is no direct limit for … the size of container
  images you can deploy."* The brief said neither platform's docs state a maximum image
  size. That is a documented absence of a limit, not a measurement of a 1 GB image.
- Cloud Run may 404 `/healthz` on `run.app` (community reports; not in Google's docs).
  The contract has `/health` too, and the acceptance test checks both.
- The HF paywall rests on a UI quote in a forum thread and the pricing page, with no staff
  reply.
