## 4. Leakage and protocol checks

- Partition 5 is read only by `--evaluate --test`; the manifest records `touches: 1` and the script refuses a second test run and a second freeze.
- Raw detection scores reproduce from the saved weights: max |difference| 0.00e+00, decisions identical (tolerance 1e-9); `--evaluate` fails otherwise.
- Inner early stopping holds out whole clusters; fold thresholds are nested and never see the scored fold.
- The label table (streamed from the corpus) and the feature table agree on every row's detection label or the run stops.
- `crf.py --check` passes without data bytes (`crf: ok`, crf_metrics.json present).
- The bundle loader refuses a missing per-task head key (parametrized test over the six keys); the localization contract is unchanged.

## 8. Deviations

1. **Signal peptide only, 2 tags (O, S)** (gate B): mitochondrial (18) and chloroplast (9) positives are under the 20-example floor, so both are undefined and not trained.
2. **A bug in `--freeze` was found and fixed in this phase**: the tag-scope block counted transit positives from the whole-corpus label table (1,173 / 783) instead of the subset (18 / 9), so the first freeze refused with "marked undefined but has enough positives". It wrote nothing; the fix counts the subset (`_subset_counts`); the second freeze succeeded.
3. **`head.frozen_sha256` is the SHA-256 of the training record**, not of the manifest (circular).
4. **Per-task head contract** (`TASK_HEAD_KEYS` in `registry/bundle.py`); the localization contract is unchanged.
5. **Selection is by cleavage +-1**, so grid points 2 and 7 (mean fold MCC 0.930) lost to grid 1 (0.894) on the first criterion.
6. **`--smoke` runs** tested the code on real data; no number from them appears here.
7. **A stale `.git/HEAD.lock`, `.git/objects/maintenance.lock` and `tmp_obj_*` files** were deleted after your approval (gate E).
8. **The refuse-to-start check and `MAX_BATCH_SEQUENCES` are deferred to Phase 14** (gate F), as for the localization head.
